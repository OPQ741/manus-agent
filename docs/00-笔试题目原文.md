### 4.3 在线体验·最小验证路径（对着必含①逐条点）

1. 打开线上链接 → 首页输入「做一个记账应用，叫「小账本」，主色墨绿」→ 自动进工作台；
2. 左侧先出**方案卡**，再逐个文件流式落字（真实行数）——对应 Atoms 环节①②；
3. 右侧沙箱里出现**真的能点**的记账应用，记一笔账 → 点刷新 → 数据仍在——环节③；
4. 对话里说「主色换成墨绿，加一个分类占比条」→ 只重写受影响文件、版本 +1——环节④；
5. 预览工具栏「设计」→ 点色卡/拖圆角 → 当场变色（不走模型、不重载页面）；点「恢复默认」清除微调，**刷新后回到生成时配色**；
6. 顶栏「导出」下载 ZIP，解压双击 `index.html` 离线可跑；「分享」复制免登录链接（自动带上访问口令）。
